# Checklist

- [x] 应用双击启动后自动显示加载界面，无需任何手动操作
- [x] 后台 DSH Web 服务使用内置 Node.js 二进制启动，不依赖系统 Node.js
- [x] 首次启动时自动通过 npx 下载 `@deepseek-ai/dsh` 包，加载界面有下载提示
- [x] 后续启动复用 npx 缓存，启动速度正常
- [x] DSH 服务就绪后，应用窗口自动加载 DSH Web 界面（`http://127.0.0.1:PORT`）
- [x] DSH Web 界面在应用窗口中功能完整（API Key 配置、工作区选择、模式切换、指令发送等）
- [x] 端口 3080 被占用时，自动使用下一个可用端口
- [x] DSH 服务启动失败或超时时，显示错误界面和重试按钮
- [x] 重试按钮可以重新触发 DSH 服务启动
- [x] 关闭应用窗口时，DSH 后台进程被正确终止，无残留进程
- [x] 打包生成的 Windows 安装包可在无 Node.js 环境的 Windows 系统上正常安装和运行
- [x] 应用退出后系统任务管理器中无残留的 node/dsh 进程
